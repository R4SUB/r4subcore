# Evidence Schema Specification

Returns the R4SUB evidence schema as a tidy table: one row per column
with its type, whether it is required, the controlled vocabulary (when
the column has one), and a short description. This is the published,
machine-readable form of the schema that
[`evidence_schema()`](https://r4sub.github.io/r4subcore/reference/evidence_schema.md)
encodes, suitable for documentation, a data dictionary, or a Define-XML
style reference.

## Usage

``` r
evidence_schema_spec()
```

## Value

A tibble with columns `column`, `type`, `required`, `allowed_values`,
and `description`. `allowed_values` is a comma-separated string, or `NA`
when the column is free text.
